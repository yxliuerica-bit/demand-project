# 电力运输需求全流程图表说明

## 版本判断

- 《电力需求预测_260426.pptx》及图表脚本包属于分部门用电需求方案，2035年全社会用电量为14.154万亿千瓦时。
- 当前货运项目的基准情景来自 `Sce_中增长` 分省模型，2035年用电量为14.534万亿千瓦时。该结果已经进入电煤需求、供需匹配、OD和运输方式流程，因此全流程展示以当前项目结果为准。
- PPT分部门结果可用于解释用电需求来源，但不能与当前电煤货运数值直接拼接。若要使用PPT的行业结构图，需要先把各部门预测统一校准到当前全国用电总量。

## 当前换算链

全社会用电需求 → 火力发电量 → 单位供电煤耗 → 电煤需求 → 分省供需匹配 → 省际OD → 公路/铁路/水运。

2035年：用电量14.534万亿千瓦时，火电量6.160万亿千瓦时，电煤需求17.556亿吨标准煤，省际电煤运输9.345亿吨标准煤。
